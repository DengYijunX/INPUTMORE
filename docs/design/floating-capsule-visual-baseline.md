# InputMore 浮窗视觉基线

## 已确认方向

采用 Warm Gray Glass 视觉语言，结合动态伸缩状态和日夜主题。

## 状态尺寸

```text
Idle       → 最小胶囊，仅保留麦克风图标
Recording  → 中等宽度，显示波形与 REC
Processing → 最大宽度，显示处理状态与 × 取消按钮
Completed  → 收缩为短暂 DONE / UNDO 提示
```

## 日间主题

- 暖白 / 银灰磨砂玻璃；
- 深石墨文字与图标；
- 低对比度暖灰边框；
- 柔和轮廓阴影；
- 杂乱背景下适当提高不透明度。

## 夜间主题

- 烟熏暖灰 / 深石墨玻璃；
- 暖白文字与图标；
- 细而清晰的浅色边框；
- 仅围绕胶囊轮廓扩散的柔和阴影。

## 交互视觉规则

- Recording 不显示取消按钮，第二次主快捷键结束录音；
- Processing 显示明显但克制的 `×`，点击立即取消并回到 Idle；
- Completed 短暂显示 `DONE` 与 `UNDO`，随后自动消失；
- 外层 Tauri 窗口保持透明，不产生矩形底板或系统阴影；
- 胶囊顶部区域可拖动窗口。

## 参考图

本方案以本次会话确认的 Warm Gray Glass 日夜状态概念图为视觉参考。后续代码实现以本文件中的状态、尺寸、材质和对比度规则为准。

## 当前实现边界

当前 Tauri 开发窗口固定为 380×90，以容纳 Processing 状态的最大胶囊；卡片本身根据状态缩放。后续接入原生窗口 resize 后，再让 Idle / Recording / Processing 使用不同的真实窗口尺寸。
