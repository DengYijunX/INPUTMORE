# InputMore v0.1.0

More power for every input.

## Highlights

- Windows desktop floating input layer
- Voice transcription with write-back to the active app
- Text enhancement for typed or selected text
- Translation preview and copy
- Occasional web retrieval with source links
- Local provider configuration for ASR, LLM, and search

## Notes

- Windows-first early release
- API keys are stored locally in the current release
- The installer is unsigned, so Windows SmartScreen may show a warning

## Install

Download `InputMore_0.1.0_x64-setup.exe` and run it on Windows 10 or later.
