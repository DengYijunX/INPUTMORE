# InputMore 当前产品状态与路线图

## 当前定位

InputMore 是一个模型无关的桌面 AI 输入增强层。它把语音或文本输入送入明确的处理链路，再将结果写回当前应用或留在浮窗中供用户复制。

## 已实现功能

### 1. 原文原写（Raw Write）

`右 Alt` 点击切换：第一次按下开始录音，第二次按下结束录音。

```text
录音 → ASR 转录 → 原文写回当前输入位置
```

默认不调用 LLM，设置中可以选择开启 LLM 整理。

### 2. 转写 / 整理（Enhance）

支持两种输入方式：

- 浮窗“文本”入口：输入或粘贴文本；
- `Ctrl + 右 Alt`：处理当前应用中已选中的文本。

```text
文本 / 选区 → 一次 LLM 整理 → 浮窗预览 → 用户复制
```

当前不会自动写回原输入框，因为启动浮窗后原应用焦点可能已经变化。

### 3. 基础能力

- Windows 桌面浮窗和全局快捷键；
- 阿里云等 ASR Provider 配置；
- OpenAI-compatible LLM Provider 配置；
- 跨应用原文写回、撤回和复制兜底；
- 选区读取失败保护、剪贴板恢复和后台耗时日志。

## 当前仍在完善的功能

### 检索 / 问答（文本 MVP）

问答和检索统一为一个显式触发的功能，后续流程为：

```text
文本 / 语音 → 检索或直接回答 → 浮窗展示答案和来源 → 用户复制
```

当前 MVP 支持文本入口、智谱 Web Search、一次 LLM 答案生成、来源展示和复制。结果在同一浮窗中以可滚动面板展示，不自动写回。

暂不做多轮 Agent 和复杂工具编排。

### 翻译（文本 MVP）

翻译已接入浮窗文本入口和目标语言配置，当前结果以预览和复制为主，尚未接入语音翻译快捷键和自动写回。

### 其他暂缓项

- Prompt 自动改写；
- 多模型自动路由；
- ChatGPT Plus、Claude Pro 等订阅权益复用；
- 聊天历史和云端历史同步；
- 流式输出。

## 当前快捷键

| 快捷键 | 行为 |
|---|---|
| 右 Alt | 原文原写：开始 / 结束录音 |
| Ctrl + 右 Alt | 选中文字转写；没有选区时提示未检测到选中文字 |

## 后续路线

1. 用真实 Provider 验证检索 MVP 的结果质量、来源和失败恢复；
2. 增加语音翻译快捷键和更完整的翻译写回流程；
3. 增加 SearXNG、Tavily 等搜索 Provider；
4. 增加 Provider、模型和请求参数的可观测性；
5. 再评估流式输出、语音检索和本地模型。
