- `npm run build`：TypeScript 检查和 Vite 生产构建通过。

- `git diff --check`：通过，无空白错误。

## 已确认的实现范围

- 整理结果进入 `writingBack` 状态后自动调用输出端口。
- 输出端口保存原纯文本剪贴板，写入结果，恢复前台窗口，发送粘贴，并在结束时恢复原剪贴板。
- 写回失败保留结果，并提供复制结果入口。
- 取消会递增会话版本号、终止处理并阻止后续写回。
- Rust 侧已注册前台窗口捕获、焦点恢复和 Windows `Ctrl+V` 命令。
