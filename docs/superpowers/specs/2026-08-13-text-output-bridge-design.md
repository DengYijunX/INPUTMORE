# 文本输出桥接设计

## 目标

在 Windows 上将整理结果自动写入用户触发快捷键前正在使用的文本输入位置：有选中文本时替换选区，没有选中文本时插入光标位置。输出失败时保留结果并提供复制兜底，不让取消或异常流程误写入。

## 已确认的交互契约

1. 用户在目标应用的输入框中按下快捷键。
2. InputMore 记录当前前台窗口作为输出目标。
3. 用户录音，停止后完成 ASR 和文本整理。
4. 整理结果生成后自动写回目标输入位置。
5. 目标应用负责按照常规输入行为处理选区：存在选区则替换，没有选区则插入。
6. 写回成功后浮窗进入完成状态，并允许用户撤销或再次启动。
7. 用户取消、任务过期或处理失败时不执行写回。
8. 写回失败时不丢结果，浮窗提供复制结果入口。

## 方案

业务层只依赖 `TextOutputPort`，不直接依赖 Windows API、剪贴板实现或 Tauri 命令。Windows 适配器负责：捕获目标窗口、保存剪贴板文本、恢复目标窗口、写入临时文本、发送粘贴输入、恢复剪贴板，并返回结构化结果。

第一版采用“剪贴板 + 粘贴事件”作为 Windows 输出通道。它能自然复用目标应用的编辑语义：选区会被替换，光标处会插入。原生 UI Automation 不作为 MVP 的主通道，因为不同应用的文本控件支持程度不一致，且接入范围更大；后续可以在同一个端口实现按应用能力选择的适配器。

## 分层边界

### 领域层

- 定义 `TargetContext`、`OutputResult`、`OutputError` 等纯数据类型。
- 定义 `TextOutputPort` 接口。
- 不包含 Tauri、Windows、剪贴板和键盘事件代码。

### 应用层

- 在结果生成后调用输出端口。
- 只有当前会话仍有效且状态为 `writingBack` 时允许写回。
- 成功发送 `writeback_succeeded`；失败发送可重试的 `failed`。
- 取消时使会话失效，阻止稍后完成的异步写回。

### 基础设施层

- Tauri clipboard-manager：读写纯文本剪贴板。
- Windows native bridge：记录前台窗口、恢复前台窗口、发送 Ctrl+V。
- 将基础设施错误转换为稳定的领域错误，不向 UI 暴露厂商或系统 API 细节。

### UI 层

- `writingBack` 显示短暂处理中状态。
- `completed` 显示已写入反馈和撤销入口。
- `error` 显示失败原因及“复制结果”入口。
- UI 不直接调用剪贴板或模拟键盘。

## 输出时序

```text
captureTarget
  -> resultReady
  -> writingBack
  -> restoreTargetWindow
  -> saveClipboardText
  -> writeResultText
  -> sendPasteShortcut
  -> waitForPasteWindow
  -> restoreClipboardText
  -> writebackSucceeded
```

每个会话带有唯一 `sessionId`。在恢复焦点、粘贴和恢复剪贴板前后都检查会话是否仍然有效；无效会话只清理临时资源，不发送粘贴事件。

## 剪贴板策略

- MVP 保存和恢复纯文本剪贴板内容。
- 如果读取原剪贴板失败，不执行自动写回，直接进入失败状态并允许复制结果。
- 写入结果后只在确认粘贴流程完成或超时后恢复原剪贴板。
- 若检测到剪贴板已被其他程序修改，则不覆盖最新内容，并记录恢复被跳过的原因。
- 不保存剪贴板到历史记录，不上传剪贴板内容。

## 焦点与权限边界

- 目标窗口句柄只在当前会话内存中保存，任务结束后释放。
- InputMore 浮窗不应在录音和处理期间永久夺取目标输入焦点。
- Windows 的前台窗口切换可能被系统限制，因此恢复焦点和发送粘贴必须返回可诊断错误。
- 后续安装包需要明确说明：自动写回需要模拟输入及剪贴板权限；不允许时仍可使用复制结果。

## 取消、超时和异常

- 录音、识别、模型处理阶段取消：终止任务，不写回。
- 写回阶段取消：若尚未发送粘贴，终止并恢复剪贴板；若已发送粘贴，不尝试反向修改目标文档，只提供用户可执行的撤销。
- 目标窗口已关闭或无法激活：失败并保留结果。
- 粘贴超时：失败并尽力恢复原剪贴板。
- 任何异常都只能使当前会话失败，不能阻塞下一次快捷键。

## 测试策略

- 领域单元测试：接口调用顺序、取消后不写回、失败状态保留结果。
- Windows 适配器测试：使用可注入的剪贴板、窗口和输入驱动模拟成功、焦点失败、剪贴板恢复冲突。
- 集成手工验证：记事本、浏览器文本框、VS Code、聊天软件各测试光标插入和选区替换；同时测试原剪贴板恢复、取消和写回失败。

## 非目标

- 不实现完整 UI Automation 文本控件适配。
- 不实现 macOS/Linux 输出通道。
- 不实现富文本、图片、文件拖拽或表格写回。
- 不把 ChatGPT Plus、Claude Pro 等订阅复用接入本功能。
