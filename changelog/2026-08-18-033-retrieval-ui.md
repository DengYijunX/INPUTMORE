## 核心改动

- 右 Alt 和 Ctrl + 右 Alt 行为保持不变。
- 浮窗“检索”按钮进入文本输入状态。
- 检索配置和 API Key 只保存在本机 localStorage。
- 检索结果在当前 Tauri 窗口中展示，不创建第二个原生窗口。
- 结果区域限制最大高度并支持滚动，展示答案、来源链接和复制按钮。
- 未配置搜索 Provider 或 LLM 时给出明确错误。
